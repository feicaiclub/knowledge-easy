# Media Slots in Component Examples

Only the source examples for Chinese layouts are maintained. Earlier screenshots have been removed. Original third-party film clips and stock videos are not included in the Skill.

To run the component examples yourself, point --media-dir to your own media directory. Common slots are street.mp4, blue.mp4, book.mp4, chess.mp4, and notes.mp4. The base components also use clock.mp4, portrait.mp4, rain.mp4, and typing.mp4. These filenames are replaceable slots, not requirements to use particular film clips. The command reports missing files.

Choose footage for each new film based on its script; these slots and example shots are not required. Original drawing examples do not require stock footage. See [Media Sources and Records](../../../references/assets.md).
