# 组件示例的素材槽位

当前只保留中文布局的源码示例。旧版截图已移除。原始第三方影视和库存视频不随 Skill 提供。

需要自行运行组件示例时，通过 --media-dir 指向自己的素材目录。常用槽位为 street.mp4、blue.mp4、book.mp4、chess.mp4、notes.mp4；基础组件还使用 clock.mp4、portrait.mp4、rain.mp4、typing.mp4。文件名只是可替换的槽位，不限定某个影视片段。命令会报告缺少的文件。

新视频按实际文稿选择素材，不必使用这些槽位或示例镜头。原创绘图示例不需要库存视频。参见 [素材选择](../../../references/assets.md)。
